# Code of conduct

This is a small, friendly project. The expectations are simple.

## Be respectful

Treat others with respect in issues, pull requests, and any other interaction.
Assume good intent, keep feedback constructive, and skip the personal attacks,
harassment, and demeaning comments.

## Keep it on topic

Issues and discussions are about the illustrations and the site. That's it.

## Enforcement

If someone's behaviour is a problem, report it to hello.claybase at gmail dot com.
Reports are handled privately. As maintainer I may edit, hide, or remove
contributions and block accounts that don't follow this code.

This is adapted in spirit from the [Contributor Covenant](https://www.contributor-covenant.org).
