# Security policy

This is a static, client-side site with no backend and no user accounts. Favorites
and display settings live only in the visitor's browser (localStorage); nothing is
sent to a server.

## Reporting a vulnerability

If you find a security issue, please report it privately rather than opening a
public issue:

- Use GitHub's [private vulnerability reporting](https://github.com/feustpat/claybase/security/advisories/new), or
- Email hello.claybase at gmail dot com

I'll try to acknowledge reports within a few days. Since this is a personal
project maintained in spare time, fixes are best effort.
